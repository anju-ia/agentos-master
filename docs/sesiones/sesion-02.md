# Sesión 2 · Entendiendo el sistema completo

## Objetivo
Entender cómo funciona un sistema de agentes de extremo a extremo.

## Qué construimos conceptualmente
Un sistema mínimo tiene 4 piezas:

1. Interfaz  
Donde el usuario interactúa (chat tipo WhatsApp / ChatGPT)

2. Backend  
Donde vive la lógica

3. Agente  
El “cerebro” que responde

4. Herramientas  
Funciones externas que el agente puede usar

## Qué aprendí en esta sesión
- No estoy “programando pantallas”, estoy diseñando sistemas
- Un agente sin herramientas es limitado
- La interfaz no es el producto, es solo la puerta

## Decisión importante
El proyecto principal (AgentOS) no será solo un chat, sino:

Una plataforma donde:
- descubres agentes
- los configuras
- los usas como si fueran contactos

## Output de la sesión
- Estructura clara del sistema
- Dirección del producto definida
