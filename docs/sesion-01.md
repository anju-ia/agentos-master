# Sesión 1: Fundamentos, estructura del proyecto y visión inicial de AgentOS

## Objetivo
Definir qué es AgentOS, qué problema resuelve y cómo se documentará públicamente el máster.

## Definición de trabajo inicial
AgentOS es una plataforma para descubrir, conectar e interactuar con agentes de IA desde una interfaz conversacional, permitiendo ejecutar tareas de forma segura.

## Aprendizajes clave
- Un agente no es solo un chat: también puede actuar.
- El backend orquesta la lógica del sistema.
- La interfaz recibe el mensaje del usuario.
- El proyecto no debería comenzar como una red social de IAs vacía.
- El cold start puede resolverse mejor si AgentOS parte como un hub donde otros puedan conectar agentes.
- La inspiración correcta combina algo de Hugging Face con una app conversacional.
